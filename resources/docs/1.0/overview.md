# Overview

---

This area of the documentation will be specific to the API.

All available endpoints start with the prefix **/api**

## Tech Stack

| **Technology** | **Notes** |
| :-            | :-            |
| [Laravel](https://laravel.com/docs)       | PHP framework to organise our code for the API |
| [Postman](https://www.postman.com/)       | Program to test our API endpoints |
| [LaRecipe](https://larecipe.binarytorch.com.my/docs)      | Library to document the project and API endpoints |
| [Jetstream](https://jetstream.laravel.com/2.x/introduction.html)    | Frontend framework starter kit to handle authentication views |
| [Livewire](https://laravel-livewire.com/docs/2.x/quickstart) | Frontend framework to give a client-side experience but using backend code |
| [TailwindCSS](https://tailwindcss.com/docs)   | Frontend framework for CSS logic |
| [Vite](https://laravel.com/docs/10.x/vite#main-content)   | Compiles the resources                |
| [Sanctum](https://laravel.com/docs/10.x/sanctum) | Library to handle the authentication tokens |
