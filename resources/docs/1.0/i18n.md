# Internationalisation (i18n)

---

Thinking big picture, this we build the app with support for more languages. For now we are supporting English (`en`). To get the languages across the application we need to implement a few different solutions.

* [Summary of functionality](#summary)
* [Frontend (ReactJS)](#react)
* [Backend (Laravel)](#laravel)

<a name="summary"></a>
## Summary of functionality

Where ever there is static text in the app or frontend; either add it to the language keys as a translation; or at a minimum, wrap the text with a translation function.

---

<a name="react"></a>
## Frontend (ReactJS)

We are using the [i18next](https://www.i18next.com/) framework via the [react-i18next](https://react.i18next.com/) module in React to handle the translations.

### Include languages for component

Using a similar example provided in their [`useTranslation` documentation](https://react.i18next.com/latest/usetranslation-hook):

```javascript
import { useTranslation } from "react-i18next";

...

const ExampleComponent = ({ ...props }) => {

    const { t } = useTranslation();

    return (
        <p>{t('hello')}</p>
    );
}

export default ExampleComponent;
```

Which would pull a translation from the selected language `src/Translations/{lang}/translations.js`

eg: `en`

```javascript
export const TRANSLATIONS_EN = {
    hello: "Hello mate"
}
```

eg: `en-US`

```javascript
export const TRANSLATIONS_EN_US = {
    hello: "Yo"
}
```

<a name="laravel"></a>
## Backend (Laravel)

We are using the built in [Localization](https://laravel.com/docs/8.x/localization) to handle the PHP strings. Anything saved in the database, will need to be translated separately (not in scope at this time).

Basically you just need to use `__()` function around text. For example:

```html
<div class="title">{{ __($pageTitle) }}</div>

...

<div>{{ __("This text can be translated") }}</div>
```

And then add a translation in the `.json` files in `resources/lang/{lang}.json`.

eg. `en`

```json
{
    "This text can be translated": "Hey, this text can be translated"
}
```

For areas of the backend which are common (such as the admin area), use the keys to grab your language eg:

```php
__('fullstacker.create_success', ['name' => 'user']))
```

This would be in a PHP array file in `resources/lang/en/fullstacker.php`
